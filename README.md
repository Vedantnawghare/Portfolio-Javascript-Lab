# Vedant Nawghare — Premium 3D Developer Portfolio

A high-performance, cinematic personal portfolio built in an editorial **Light Theme**, crafted strictly using **HTML5**, **CSS3**, and **Vanilla JavaScript (ES6+)** with **zero external libraries or build dependencies**.

Designed for **Vedant Dinesh Nawghare**, Computer Science and Engineering — Data Science undergraduate at Symbiosis Institute of Technology, Nagpur, published IEEE researcher, and AI/ML practitioner.

---

## ⚡ Strictly 3 Technologies — Zero External Dependencies

- **HTML5**: Semantic landmark structure, SEO metadata, Open Graph cards, accessible dialogs, and ARIA attributes.
- **CSS3**: Custom properties, CSS 3D perspective (`preserve-3d`), editorial light theme typography, keyframe orbital physics, and responsive media queries.
- **Vanilla JavaScript (ES6+)**: Interactive 3D tilt, canvas 2D spatial fields, real-time waveform & ECG telemetry, dynamic IST clock, terminal emulator, filter systems, and accessible modal lightbox.

### 🚫 Prohibited & Avoided
No React, Next.js, TypeScript, Vue, Three.js, GSAP, Framer Motion, Tailwind CSS, Bootstrap, jQuery, npm modules, or backend runtimes.

## 🚀 How to Run Locally

Because this project uses standard web technologies with no compilation or build steps, you can run it immediately using any of these methods:

### Method 1: Direct File Opening
Double-click `index.html` or open it in any modern browser (Chrome, Edge, Firefox, Safari).

### Method 2: Python HTTP Server
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.
